What's new

Every line in a briefing earns its place.

resume · status · shownew

Concurrent-work notices

Other branches and worktrees that changed files in your scope, or recorded decisions about it, since they split. Uncommitted records count, labeled.

validate · resume · mcp

Checked before compiled

Briefings, PR summaries, MCP resources, and the dashboard share one set of checks. Invalid, forged, or secret-bearing records are withheld and reported.

receipt run

Receipts that ran

Alethic observes the check itself and records content digests before and after, so a pass stops applying once that code changes.

resume --budget · show

Bounded briefings

Briefings stay within budget as the ledger grows. Collapsed lines cite at most five records, and alethic show reads any of them in full.

ALETHIC_SESSION

Parallel sessions

Sessions are named, leases are session-aware, and record writes are locked and version-checked, so competing claims surface instead of overwriting.

anchors · verify

Anchored to code

Records fingerprint the files they describe. When that code changes they read as may be stale, even after squash merges and shallow clones.
